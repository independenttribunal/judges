# Judges database: public site

Served at **https://judges.independenttribunal.org/** (until DNS is set: https://independenttribunal.github.io/judges/).

This repository holds only the built site. It is generated daily from the
Independent Tribunal judges database and overwritten on each build, so edits
made here will be lost. Corrections and sources:
https://github.com/independenttribunal/independenttribunal-www/issues

What is published: the official roster of judges as judiciary.uk publishes it
(Open Government Licence v3.0), and aggregate counts. Nothing attributing a
decision to a named judge is published until a person has checked it against
the source.
